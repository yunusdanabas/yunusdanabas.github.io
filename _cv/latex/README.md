# Yunus Emre Danabaş CV LaTeX Project

Edit `YunusEmreDanabas_CV.tex`, `preamble.tex`, or files under `sections/`.

Build once and sync the website PDF:

```bash
./build.sh
```

Watch while editing and sync after every successful rebuild:

```bash
./build.sh watch
```

Outputs:

- `YunusEmreDanabas_CV.pdf`
- `../../assets/pdf/YunusEmreDanabas_CV.pdf`
